# W4 — Успеваемость

## Задача для воркера

Реализовать раздел «Успеваемость» (docs/ARCHITECTURE.md — истина).

### Что сделать

1. **API** `GET /api/grades?term=<семестр>`:
   - Данные только студента из сессии (проверка владения).
   - Ответ: оценки/зачёты по дисциплинам с типом контроля (экзамен/зачёт/курсовая), значением, датой, семестром.

2. **UI** `/grades`:
   - Сводка «Как у меня дела»: средний балл (по 5-балльной шкале, экзамены), количество сданных/несданных зачётов, долги (2 или незачёт), тренд к прошлому семестру (стрелка вверх/вниз и цифра).
   - Фильтр по семестру (сегменты: текущий / предыдущий / всё).
   - Список дисциплин: название, оценка/зачёт (бейджем), дата, тип контроля.
   - Долги — визуально выделены (предупреждающий цвет).
   - Пустые состояния: «В этом семестре оценок ещё нет».
   - Скелетоны и обработка ошибок.

3. Таб-бар: «Оценки» активен.

4. Проверка: `npm run build`; у student1 и student2 разная успеваемость — видно в разных цифрах.

5. Коммит: `feat(grades): успеваемость и сводка`.
