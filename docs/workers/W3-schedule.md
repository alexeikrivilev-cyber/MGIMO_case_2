# W3 — Расписание

## Задача для воркера

Реализовать раздел «Расписание» в кабинете студента (docs/ARCHITECTURE.md — истина).

### Что сделать

1. **API** `GET /api/schedule?mode=today|week&date=YYYY-MM-DD`:
   - Группа берётся из сессии (session.user.student.groupId), НИКОГДА из query — иначе IDOR.
   - Ответ: занятия с предметом, типом (лекция/семинар/лаба), временем, аудиторией, преподавателем, статусом (SCHEDULED/MOVED/CANCELLED), примечанием.
   - Сериализация дат в локальной таймзоне ( Europe/Samara не предполагать — использовать таймзону сервера/UTC корректно, хранить Date в UTC).

2. **UI** `/schedule`:
   - Переключатель «Сегодня / Неделя» (таб-бар или segmented control).
   - «Сегодня»: занятия на текущий день, сверху — дата и день недели; пустые состояния («Сегодня пар нет»).
   - «Неделя»: мобильный список по дням (Пн–Вс) с группировкой, текущий день подсвечен; на десктопе — сетка/колонки.
   - Бейджи: «Перенесена» (MOVED) с пояснением откуда, «Отменена» (CANCELLED) — зачёркнутый вид.
   - Навигация: стрелки/свайп предыдущая/следующая неделя, кнопка «Эта неделя».
   - Скелетоны на время загрузки, обработка ошибок сети с кнопкой «Повторить».

3. Навигационный таб-бар: сделать «Расписание» активным разделом.

4. Проверка: `npm run build`; сценарий student1 → расписание его группы ИТ-21-1 содержит перенесённую и отменённую пары.

5. Коммит: `feat(schedule): расписание на сегодня и неделю`.
