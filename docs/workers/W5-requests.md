# W5 — Заявки и справки

## Задача для воркера

Реализовать раздел «Заявки и справки» (docs/ARCHITECTURE.md — истина).

### Что сделать

1. **API**:
   - `GET /api/requests` — список заявок студента из сессии (+ фильтр по статусу).
   - `POST /api/requests` — создание: тип (справка: об обучении / в военкомат / вызова на сессию; заявление: академический отпуск / перевод / стипендия), поля формы (количество копий, язык, цель, комментарий), валидация zod.
   - `GET /api/requests/[id]` — детали; ПРОВЕРКА ВЛАДЕНИЯ: 404 (не 403) если заявка не принадлежит студенту из сессии.

2. **UI** `/requests`:
   - Кнопка «Новая заявка» → форма (bottom-sheet на мобильном / модалка на десктопе): выбор типа, динамические поля, комментарий; состояния загрузки и ошибок; успех — тост/редирект в список.
   - Список заявок: тип, дата, статус бейджем (NEW — «Принята», IN_PROGRESS — «В работе», READY — «Готова», REJECTED — «Отклонена»), комментарий сотрудника если есть.
   - Детали заявки: история статусов, что делать дальше (напр. «Готова к выдаче в 301 ауд.»).
   - Пустые состояния, скелетоны.

3. Таб-бар: «Заявки» активен.

4. Тест IDOR: будучи student1, запрос заявки student2 → 404. Закоммитить тест (простой unit/e2e — что доступно в проекте; минимум — ручной сценарий в README раздела или скрипт проверки).

5. Коммит: `feat(requests): заявки и справки`.
