# W7 — Кабинет сотрудника деканата

## Задача для воркера

Реализовать кабинет сотрудника деканата (docs/ARCHITECTURE.md — истина).

### Что сделать

1. **API** (все проверки роли STAFF/ADMIN + привязка к факультету сотрудника):
   - `GET /api/staff/requests?status=` — заявки студентов своего факультета (STAFF видит только свой факультет; ADMIN — все).
   - `POST /api/staff/requests/[id]/status` — смена статуса с комментарием; создаёт уведомление студенту и запись в AuditEvent.
   - `GET /api/staff/schedule` и `POST /api/staff/schedule/[id]/move` — перенос пары (новая дата/время/аудитория) с статусом MOVED и примечанием; создаёт уведомления студентам группы.
   - `POST /api/staff/announcements` — публикация объявления (заголовок, текст, аудитория: все / факультет / группа, закрепить); создаёт уведомления целевой аудитории.

2. **UI** `/staff` (отдельный layout с навигацией: Заявки / Объявления / Расписание):
   - Заявки: список с фильтром по статусу, карточка → смена статуса + комментарий.
   - Объявления: форма публикации + список опубликованных.
   - Расписание: список пар своей группы(п) на неделю, действие «Перенести» (диалог с новыми датой/временем/аудиторией).
   - Мобильный вид — приоритет.

3. Разделение доступов: студент, открывший /staff, получает 404 (не «доступ запрещён» с намёком на существование).

4. Коммит: `feat(staff): кабинет сотрудника деканата`.
