# W9 — MCP-сервер для агентов деканата

## Задача для воркера

Реализовать MCP-сервер (apps/mcp-server), чтобы ИИ-агенты сотрудников деканата работали с данными кабинета через стандартный протокол Model Context Protocol.

### Что сделать

1. `apps/mcp-server` — Node + TypeScript, официальный MCP SDK (`@modelcontextprotocol/sdk`), транспорт stdio (основной) + Streamable HTTP (дополнительно, для удалённых агентов).
2. Инструменты (tools):
   - `get_schedule` — расписание группы/преподавателя на дату/неделю.
   - `get_grades` — успеваемость студента (по студенту, только для агента с правами STAFF/ADMIN).
   - `list_requests` — заявки (фильтр по статусу/факультету).
   - `publish_announcement` — опубликовать объявление (требует роль STAFF/ADMIN).
   - `move_lesson` — перенести пару (требует STAFF/ADMIN).
3. Доступ к данным — через packages/db (Prisma) или HTTP API веб-приложения (выбрать надёжный путь; если HTTP — сервисный токен из env MCP_SERVICE_TOKEN).
4. README: пример конфигурации для клиента (claude/cursor-подобный агент деканата), список инструментов, что умеет, ограничения прав.
5. Тест: запуск сервера, вызов get_schedule через простой клиентский скрипт (положить в apps/mcp-server/examples/).
6. Коммит: `feat(mcp): MCP-сервер для агентов деканата`.
