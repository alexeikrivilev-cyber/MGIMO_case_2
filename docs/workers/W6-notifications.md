# W6 — Уведомления

## Задача для воркера

Реализовать раздел «Уведомления» (docs/ARCHITECTURE.md — истина).

### Что сделать

1. **Модель данных**: использовать/расширить модель Notification (пользователь, тип: ANNOUNCEMENT / SCHEDULE_CHANGE / REQUEST_STATUS / DEADLINE; заголовок; тело; ссылка; прочитано; дата). Если нужны миграции — создать.

2. **API**:
   - `GET /api/notifications` — лента текущего пользователя (сотрудник/админ — по роли), сортировка по дате, непрочитанные первыми.
   - `POST /api/notifications/[id]/read` — отметить прочитанной (проверка владения).
   - `GET /api/notifications/unread-count` — счётчик для шапки.

3. **UI** `/notifications` (и счётчик в шапке кабинета):
   - Лента с иконками по типу, датой («сегодня, 14:30» / «вчера» / дата), непрочитанные — акцентная точка/фон.
   - Клик по уведомлению → переход по ссылке (расписание/заявка) + отметка о прочтении.
   - «Отметить все прочитанные».
   - Пустые состояния, скелетоны.

4. Генерация уведомлений: при создании заявки — студенту «Заявка принята»; сидер уже создаёт уведомления — оставить совместимым.

5. Коммит: `feat(notifications): лента уведомлений и счётчик`.
