      заявки, уведомления, объявления, «болею», верификация. Жёсткая фильтрация по
      владельцу + тесты на IDOR. Расчёт «что подтянуть» и «леверидж» до целевой оценки.
- [x] **P1.4 API и страницы кабинета.** Route Handlers (zod, заголовки безопасности),

      расписание, расписание преподавателей, успеваемость, заявки, уведомления,
