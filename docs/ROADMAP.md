# ROADMAP — proj-3311 «Цифровой деканат будущего»

Внутренний дедлайн PO: **21 ноября 2026**. Внешний (кейс): 28 ноября 2026.
Ведёт Hermes. После каждого приоритета — приёмка PO по `docs/BRIEF.md`.

## P1 — Ядро (критичный путь)

- [ ] **P1.1 Фундамент.** npm workspaces; `packages/db` (Prisma-схема по ARCHITECTURE §3,
      миграция, сидер синтетических данных Университета «Горизонт»); `packages/ui` (токены);
      `docker-compose.yml`; README с запуском.
- [ ] **P1.2 Домен и безопасность.** `packages/core`: argon2id-хеширование, сессии
      (создание/валидация/отзыв, httpOnly-cookie), rate-limit входа, CSRF, сервисы
      расписания/успеваемости/заявок/уведомлений с жёсткой фильтрацией по владельцу,
      расчёт GPA. Юнит-тесты домена.
- [ ] **P1.3 API + страницы кабинета.** Next.js Route Handlers (zod-валидация, заголовки
      безопасности), страницы: вход, профиль, расписание (сегодня/неделя), успеваемость,
      заявки, уведомления. Мобильный 360 px, баннер концепта.
- [ ] **P1.4 Визуал.** Дизайн-направление (Council) → реализация UI через Open Design →
      интеграция, тёмная тема, пустые состояния.
- [ ] **P1.5 QA-гейт.** Полный прогон тестов, сценарная проверка в браузере (8 сценариев PRD §5),
      IDOR-проверка, 360 px, запрет заглушек. Мёрж в `master` только на зелёном.

## P2 — Глубина

- [ ] Кабинет сотрудника деканата: очередь заявок, смена статуса + комментарий, публикация
      объявлений, перенос/отмена пар (с автогенерацией уведомлений студентам).
- [ ] AI-ассистент в кабинете: ответы по данным студента, детерминированный fallback без ключа.
- [ ] MCP-сервер для агентов деканата: инструменты расписание/оценки/заявки/объявления,
      авторизация по токену агента, аудит обращений.

## P3 — Качество

- [ ] Дизайн-полировка, пустые состояния, ошибки, скелетоны загрузки.
- [ ] Тёмная тема, WCAG 2.2 AA, Core Web Vitals, PWA-оболочка.

## P4 — Сдача

- [ ] Деплой на Helsinki VPS (Docker Compose, HTTPS), проверка доступности из РФ.
- [ ] Тестовые аккаунты (2 студента + сотрудник), сквозные сценарии на проде.
- [ ] Документ процесса со скриншотами, README, (опц.) видео ≤ 5 мин, финальный чек-лист кейса.
