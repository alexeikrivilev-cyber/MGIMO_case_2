# Очередь задач для ИИ-воркеров (OpenCode)

Каждый пункт — отдельная автономная задача для `opencode-worker`. Воркеры выполняются последовательно, если трогают общие файлы, и параллельно — если независимы (разные packages).

## W1 — Скаффолд (выполнено)
Монорепо npm workspaces: apps/web (Next.js 15, Tailwind v4), packages/db (Prisma + сидер), packages/core, docker-compose (postgres:16), .env.example, README. Commit: feat: скаффолд.

## W2 — Auth + профиль (следующий)
- packages/core: argon2id-хеширование (npm: argon2 или @node-rs/argon2 — выбрать работающий на Node 24), создание/валидация сессий (httpOnly cookie, SameSite=Lax, Secure в проде, срок 7 дней), CSRF-токен.
- apps/web: /login (форма, ошибки без утечки существования логина, rate-limit 5/15мин на логин+IP — in-memory + заголовки), /api/auth/login, /api/auth/logout, middleware защиты роутов.
- Профиль студента /profile: ФИО, факультет, направление, курс, группа, email (только чтение + редактирование контактов).
- Роли: STUDENT, STAFF, ADMIN; STAFF видит свой факультет (поле faculty у User), ADMIN — всё.

## W3 — Расписание
- /schedule: переключение «сегодня/неделя», список занятий (время, предмет, тип, аудитория, преподаватель), бейджи MOVED/CANCELLED с пояснением, стрелки навигации по неделям.
- API /api/schedule с фильтром по группе студента из сессии. Мобильный вид: список по дням.

## W4 — Успеваемость
- /grades: оценки и зачёты по дисциплинам, фильтр по семестру, сводка «как у меня дела» (средний балл, долги, тренд), пустые состояния.

## W5 — Заявки и справки
- /requests: форма заказа справки (тип справки, количество, комментарий) + подача заявления; список заявок со статусами и историей; API с проверкой владения.

## W6 — Уведомления
- /notifications: лента (объявления деканата, изменения расписания, дедлайны заявок), непрочитанные, отметка о прочтении; бейдж счётчика в шапке.

## W7 — Кабинет сотрудника деканата
- /staff: список заявок своего факультета, смена статуса с комментарием, публикация объявлений (аудитория: все/факультет/группа), перенос/отмена пар с созданием уведомлений студентам.

## W8 — AI-ассистент
- Серверный сервис answers: детерминированные интенты по данным студента (расписание на сегодня/завтра, долги, дедлайны, «что подтянуть», средний балл) + опциональный LLM (ключ из env LLM_API_KEY, модель из env; без ключа — только детерминированный режим). UI: панель ассистента в кабинете.

## W9 — MCP-сервер
- apps/mcp-server: MCP SDK, инструменты get_schedule, get_grades, list_requests, publish_announcement (с проверкой прав сотрудника), транспорт stdio + HTTP. README с примером конфигурации для агента деканата.

## W10 — Дизайн-полировка, PWA, a11y
- Дизайн-токены, тёмная тема, пустые состояния/ошибки/скелетоны, PWA-манифест + service worker, проверка ≥360px, WCAG AA.

## W11 — Деплой Helsinki VPS
- Docker Compose (web+db+mcp), сборка, деплой на 177.3.196.28, HTTPS, тестовые аккаунты, проверка доступности из РФ.
