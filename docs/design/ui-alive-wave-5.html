1. Пустые состояния: иконка раздела вместо пустоты

EmptyState получает необязательный icon?: ReactNode: 40px, text-text-muted, по центру над заголовком. Иконки — из components/icons.tsx (уже aria-hidden), смысл по разделу:

  • расписание/пары → IconCalendar; заявки → IconRequests; уведомления → IconBell; объявления → IconMegaphone; успеваемость → IconGrades; ассистент → IconAssistant; переписка → IconChat; каналы → IconChannels; преподаватели → IconProfile; верификация/студбилет → IconIdCard; планы → IconRequests; переносы → IconMove.
  • Класс, не сайт: ВСЕ 29 использований получают иконку по смыслу раздела. Сторож empty-state-icon.test.ts обходит исходники и роняет прогон на <EmptyState без icon= — новый экран без иконки сразу красный.
  • Текста не добавляем ни строки (BRIEF v4): заголовок остаётся одной строкой, иконка несёт характер.

2. «Ближайшая пара»: метка «когда»

Чистая функция lessonMoment(now, date, startTime, endTime) (в components/format.ts, рядом с форматтерами) считает по UTC-мгновениям, как сервисы расписания (повторяем TZ-урок волны 2):

  • пара идёт сейчас → Сейчас (success-тон);
  • до начала меньше суток → Через 2 ч 15 мин / Через 45 мин (primary-тон);
  • больше суток → дата уже есть в карточке, метку не дублируем;
  • пара закончилась → Завершилась (нейтральная).
