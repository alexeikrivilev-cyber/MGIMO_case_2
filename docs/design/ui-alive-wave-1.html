Wave 1. Что это

Директива владельца: интерфейс «мертвый». Волна 1 — фундамент отклика и самая ценная визуализация (динамика оценок). Рамки: thinking-via-negativa (добавляем только то, что несёт информацию или отклик) и thinking-pre-mortem (контрмеры: 360 px, reduced-motion, SSR, ноль зависимостей).

1. Motion-токены (единственный источник — tokens.css)

Длительности из доктрины better-ui: высокочастотное взаимодействие — 150ms; входная хореография — 300ms. Easing — точное значение доктрины, не приближение.

ТокенЗначениеГдеПочему
--udgu-motion-duration-fast150msнажатие, hover, смена состоянияbetter-ui: высокочастотные взаимодействия отвечают мгновенно или ≤150ms
--udgu-motion-duration-base220msпереходы между состояниями (было transition-base)уже был в токенах, сохраняем
--udgu-motion-duration-slow300msвходная анимация секций и столбцовbetter-ui: stagger-вход 300ms ease-out
--udgu-motion-ease-outcubic-bezier(0.2, 0, 0, 1)все переходы и ключевые кадрыточное значение доктрины; встроенный ease-out Tailwind — другое

Зеркало в packages/ui/src/tokens.ts (тест паритета): motion: { durationFast: '150ms', durationBase: '220ms', durationSlow: '300ms', easeOut: 'cubic-bezier(0.2, 0, 0, 1)' }.

2. Отклик на нажатие (press feedback)

better-ui: нажатие масштабирует до 0.96 за 150ms ease-out; disabled никогда не масштабируется; переход — только именованные свойства, никогда all. Под reduced-motion масштаба нет (глобальное правило уже гасит длительности), остаётся смена цвета.

const PRESS_FEEDBACK =
  'transition-[transform,background-color,border-color,color] ' +
  'duration-[var(--udgu-motion-duration-fast)] ' +
  'ease-[var(--udgu-motion-ease-out)] ' +
  'motion-safe:enabled:active:scale-[0.96]';

Применяется в components/ui.tsx к Button и LinkButton (вместо transition-colors), к SegmentedLinks и к кнопкам-стрелкам WeekArrow. Остальным интерактивным элементам (поля, ссылки в тексте) — только существующие цветовые переходы.

3. Stagger первого экрана (только «Сегодня»)

better-ui: stagger 100ms доктрины применён как 80ms с капом 6 элементов — 8 секций дашборда ждали бы 800ms, это шум. Один экран получает хореографию входа: первый экран после входа. Остальные экраны — без stagger (у них свои моменты: столбцы на успеваемости). При reduced-motion анимации нет, элементы сразу на месте.

/* globals.css */
@keyframes udgu-rise { from { opacity: 0; transform: translateY(12px); filter: blur(4px); } to { opacity: 1; transform: none; filter: blur(0); } }
@media (prefers-reduced-motion: no-preference) {
  .stagger-in > * { animation: udgu-rise var(--udgu-motion-duration-slow) var(--udgu-motion-ease-out) both; }
  .stagger-in > *:nth-child(2) { animation-delay: 80ms; }
  /* …nth-child(3..6): 160/240/320/400ms */
  .stagger-in > *:nth-child(n+7) { animation-delay: 400ms; } /* хвост ждёт последним, но не «прыгает» без анимации */
}

5. Диаграмма — геометрия (SVG, серверный рендер, без JS)

Столбцы, а не спарклайн: 2–4 точки с подписями чисел и семестров читаются на 360 px лучше; линия без точек выглядела бы «загадкой». Шкала 2..5 (оценки УдГУ), baseline подписан. Ось без тиков — только baseline: минимум чернил. ПРОШЛЫЕ семестры — приглушённый primary, последний — полный: новость ведёт глаз. Никаких дополнительных линий: общий средний балл уже есть числом-героем в сводке выше.

  • viewBox 0 0 320 150, ширина 100% (резином до 360 px)
  • baseline y=130, вершина шкалы (5.0) y=10: y = 130 − (avg − 2) / 3 × 120
  • столбец: ширина 40, rx 4, центрирован в своей полосе; полоса = 288 / n, центр полосы x = 24 + (i + 0.5) × (288 / n), левый край x − 20
  • подпись значения: y = barY − 6, text-anchor middle, 12px, tabular-nums, цвет text
  • подпись семестра: y = 146, «1 сем», 10px, muted

Координаты сверены с формулой исполнением (не на глаз). Столбцы растут снизу (scaleY 0→1, origin bottom, transform-box fill-box) с задержкой 60ms на столбец — только под prefers-reduced-motion: no-preference. Под reduce столбцы сразу на месте. aria-label несёт все числа (дублирование текстом под графиком не нужно — записи семестров уже есть списком ниже). Никакого JS и тултипов: диаграмма — чистый серверный SVG.

6. Размещение и развилки

В SummaryCard («Как у меня дела») под сеткой «Средний балл / Тренд»: заголовок секции «Динамика по семестрам» + диаграмма. Чип тренда (стрелка + текст + цвет) остаётся в сетке — он текстовый носитель для скринридера, диаграмма — визуальный.

7. Чего в волне 1 НЕ добавлено (via negativa)

Спарклайн/линия (худше читается с подписями на 360 px) · тики осей и сетка (шум) · градиентные заливки · интерактивные тултипы (нужен JS, ломает серверный рендер) · счётчики-анимации чисел · stagger на всех экранах (только «Сегодня») · подъём карточек на hover · chart-библиотеки и framer-motion (вес без отдачи) · motion на строках списков (высокая частота — мгновенный отклик цветом).
