Wave 2. Что это

Волна 1 дала отклик (press/stagger) и визуализацию тренда. Волна 2 — наглядность там, где пользователь задаёт вопрос «где я»: статус заявки («мой запрос уже двигался?») и форма дня («какая пара сейчас/далее, где окна»). Оба элемента — серверный рендер, без JS и библиотек. Токены и отклик из волны 1 переиспользуются.

1. Таймлайн заявки (экран «Заявки», карточка заявки)

Сейчас статус — два бейджа текстом. Добавляем шаги продвижения: Новая → В работе → Готова. Три шага, не пять: в данных только три «движущихся» статуса, четвертый (Отклонена) — не «этап», а исход; для него таймлайна нет (отказ не должен выглядеть как пустой шаг). Существующие StatusBadge и «чей ход» ОСТАЮТСЯ — текстовые носители не удаляются.

  • Раскладка: flex, 3 колонки шагов, между ними соединительные линии flex-1 h-0.5
  • Точка шага: 10px, радиус full; пройден — bg-primary; текущий — bg-primary + кольцо box-shadow 0 0 0 3px primary-soft; будущий — border border-border bg-surface
  • Линия между шагами: пройдена — bg-primary, иначе bg-border
  • Подпись под точкой: 10px, nowrap; у текушего — font-semibold text-text, у остальных — text-text-muted
  • Доступность: <ol aria-label="Статус заявки">, текущий шаг — aria-current="step"; состояние НЕ только цветом (подписи + aria-current)
  • REJECTED → компонент возвращает null (таймлайна нет)

2. Рельс дня (расписание, режим «Сегодня»)

Список пар не показывает форму дня. Рельс — вертикальная ось слева: точка на каждой паре, пунктир на окнах, отметка «сейчас» в хронологической позиции. Текст НЕ приглушаем сильнее text-muted (контраст — триггер доступности): прошедшие пары отличаются полой точкой, текущая — залитой с кольцом и чипом «Сейчас», следующая — чипом «Далее». Отклонённая — точка danger (ряд и так зачёркнут с бейджем).

  • Компонент DayTimeline (серверный): props { lessons: ScheduleLesson[]; gaps: FreeGap[]; now: Date }
  • Рельс: контейнер relative pl-5, линия absolute left-1 top-2 bottom-2 w-0.5 bg-border (псевдоэлемент или div)
  • Пара: li relative, точка 10px на линии (left −20px, top 14px): пройдена — bg-primary border-primary; текущая — то же + ring (box-shadow 0 0 0 3px primary-soft); будущая — bg-surface border-2 border-border; отмененная — border-danger
  • Содержимое ряда — КАК в LessonRow (предмет, тип · аудитория, ссылка на преподавателя, бейджи переноса/отмены), но без временного gutter: время уезжает в рельс? НЕТ — время остаётся в ряду (как в LessonRow), рельс добавляет только точки/окна/«сейчас». Дублирования времени нет.
  • Окно (gap): пунктирный сегмент на рельсе + подпись длительности одной строкой muted («1 ч 20 мин», формат formatDuration)
  • Отметка «сейчас»: строка-маркер с чипом «Сейчас» встаёт в хронологической позиции: до первой пары, внутри окна или после последней пары («пары закончились» — чип нейтральный). Если сейчас идёт пара — маркер-строка не нужен, текущая пара помечена чипом «Сейчас»
  • now приходит из серверного компонента экрана (new Date()), вид принимает опциональным пропом с дефолтом — тесты детерминированы
  • Утро/вечер: шкала дня НЕ рисуется (нет тиков часов — только события), «сейчас» — единственная привязка ко времени
